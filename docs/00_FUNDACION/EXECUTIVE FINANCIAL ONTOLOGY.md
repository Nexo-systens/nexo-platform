# EXECUTIVE FINANCIAL ONTOLOGY

Versão 1.0

---

# Objetivo

A Ontologia Financeira Executiva define todas as entidades, conceitos e relações que existem dentro do EFOS.

Ela representa o conhecimento permanente da plataforma.

Toda decisão produzida pelo EFOS deve ser construída utilizando essa ontologia.

---

# Princípio Fundamental

O EFOS não interpreta documentos.

O EFOS interpreta empresas.

Documentos são apenas fontes de informação.

---

# Entidade Raiz

Empresa

Toda informação pertence a uma empresa.

Nada existe isoladamente.

# Camada 8 — Decisões

Representam escolhas humanas.

---

# Camada 9 — Conhecimento

Conhecimento permanente.

Exemplo.

Empresa possui forte sazonalidade.

Fornecedor X costuma atrasar.

Produto Y possui maior margem.

Cliente A atrasa pagamentos.

Essas informações permanecem vivas.

---

# Regra Fundamental

Nenhuma entidade pode existir sem relacionamento.

O EFOS é uma rede de conhecimento.

Não uma coleção de tabelas.
